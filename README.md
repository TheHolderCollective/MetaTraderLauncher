# MetaTrader Launcher

A demo application showing how the MetatraderSharp API can be used to work with multiple MetaTrader terminals.

## Project Status

[19-10-2026]: Under development

## Usage Requirements
Successful usage of the MetaTrader Launcher app requires:
- multiple copies of Metatrader 4/Metratrader 5 to be installed 
- MTsocketAPI should be installed in each copy of Metatrader

For more information on how to install the MTsocketAPI please consult: https://www.mtsocketapi.com/

## Disclaimer

This is a sample application and is provided as is. It is a demo of possibiities, and not intended to be used for live trading.
